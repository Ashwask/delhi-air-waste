# Delhi Air + Waste: A Systemic Landscape

An offline, single-file dashboard that treats Delhi's air pollution and municipal solid waste as **one interlocked system**, and maps the crisis, the leverage, the current government system, and the organisations working across each stream.

**Live:** https://ashwask.github.io/delhi-air-waste/

## Tabs
1. **The Crisis** - the numbers, 5-year trend, source apportionment, the waste ledger, a Delhi hotspot map (real NCT boundary), the measures in place, who governs what, and the deadlines that are slipping.
2. **The System** - the air-waste chain as one loop, working vs not working (with numbers), and the four things to do (ranked by impact), plus the financials of what can be redirected.
3. **Action & Partners** - a stream-by-stream action map, do-first moves, financials, how a task force could be set up, and an ecosystem directory of organisations.

## Notes
